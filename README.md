# Права 필기 — подготовка к теории на корейские права

Мобильное веб-приложение (PWA) для подготовки к письменному экзамену на корейские водительские права
(학과시험, 2종 보통) по **официальному банку вопросов 도로교통공단** — и одновременно для изучения
корейских слов, из которых состоят эти вопросы.

Открыть: **https://xcaelestisox.github.io/koroad-learn/** → «Поделиться» → «На экран „Домой“» (iPhone)
или «Установить приложение» (Android). После первого открытия работает без интернета.

## Что внутри

- **1101 вопрос** официального банка (ред. 30.11.2026): текстовые, дорожные знаки, фото и иллюстрации,
  с картинками и официальными объяснениями (해설). Корейский текст — дословно из PDF, русский перевод
  по кнопке, любое подчёркнутое слово переводится по нажатию.
- **Интервальные повторения (FSRS)**: ошибки возвращаются в той же сессии и по расписанию.
- **Слова из банка** по частоте: каждое показано внутри настоящего вопроса экзамена.
- **Пробный экзамен** как настоящий: тот же состав вопросов, 40 минут, разбор в конце.
- Прогресс хранится на телефоне; его можно сохранить в файл и загрузить обратно.

Как сделан и проверен контент: [docs/CONTENT.md](docs/CONTENT.md).
Какие практики мобильного дизайна применены и почему: [docs/DESIGN.md](docs/DESIGN.md).

## Разработка

```sh
pnpm install
pnpm dev      # http://localhost:5173
pnpm test
pnpm build    # apps/web/dist, деплой на GitHub Pages из main (.github/workflows/ci.yml)
```

| Путь | Что это |
|---|---|
| `apps/web` | PWA: React, Vite, TypeScript, ts-fsrs; без сервера |
| `content/source` | официальный PDF банка вопросов |
| `content/scripts` | извлечение, проверка, словарь, сборка данных |
| `content/work` | промежуточные данные и результаты агентов-переводчиков и проверяющих |

Вопросы © 도로교통공단 (KoROAD), опубликованы для подготовки к экзамену; переводы — учебная подсказка,
первоисточник — корейский текст.
