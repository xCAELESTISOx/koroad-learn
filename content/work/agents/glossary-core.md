Question stems: keep the exact logic words.
- 옳은 것은? / 맞는 것은? → «Какое утверждение верно?»
- 옳지 않은 것은? / 틀린 것은? / 잘못된 것은? / 아닌 것은? / 바르지 않은 것은? → «Какое утверждение НЕВЕРНО?» (capitalize НЕ / НЕВЕРНО so the trap is visible)
- 가장 안전한 → «наиболее безопасный»; 가장 위험한 → «наиболее опасный»
- 2가지는? → «(2 ответа)»
- (   ) blanks stay as «(   )».
